# Bookshop documentation

This documentation describes the sample from the persistence model through its services to the client-facing UI boundary.

- [Database layer](database.md) — entities, relationships, persistence and validation.
- [Service layer](service.md) — CatalogService, AdminService and custom handlers.
- [UI layer](ui.md) — current API boundary and guidance for a future SAPUI5/Fiori client.

The sample is intentionally small: the backend services are implemented, while a UI application is not included in this repository.
